# Design system

The project-owned UI package defines semantic color, typography, spacing, radius,
elevation, focus, motion, chart, dark-mode, and high-contrast tokens. Operational
surfaces prioritize exception severity and next actions; storefront surfaces remain
mobile-first. WCAG 2.2 AA is the target.

Timeline components use a semantic ordered list, visible event label, location
or description, and localized occurrence time. Status may not be communicated
by color alone. A milestone timeline must be labelled as reported operational
history and must not imply live GPS when events are manually entered.
