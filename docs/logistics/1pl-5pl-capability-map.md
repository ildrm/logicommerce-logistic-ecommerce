# 1PL–5PL capability map

| Level | Foundation                                                               |
| ----- | ------------------------------------------------------------------------ |
| 1PL   | Seller inventory, fulfillment, label, tracking, return                   |
| 2PL   | Carrier adapters, rates, pickup, proof, SLA, claim                       |
| 3PL   | Multi-client WMS, ASN, bin stock, pick/pack, billing                     |
| 4PL   | Control tower, multi-provider routing, contracts, exceptions             |
| 5PL   | Network nodes/lanes, forecasts, scenarios, recommendations with approval |

Capability selection is policy-driven by tenant, contract, store, seller, and route.

Phase 12 connects these levels to a customer-facing global freight workflow:
multimodal demand and quotes, ordered legs, internal or subcontracted road
dispatch, operator milestones for all modes, proof of delivery, invoicing, and
hosted payment. See the
[freight journey timeline](freight-journey-timeline.md) for the implemented
tracking boundary.

Phase 13 adds the international execution structure that spans these levels:
governed locations and parties, consignments and transport/customs documents,
cargo-insurance coverage and claims, SSCC-addressable nested handling units,
gateway hubs, cross-booking consolidation/deconsolidation, shared linehaul
capacity, VGM evidence, custody events, and the postal
item–receptacle–dispatch–consignment hierarchy. It does not turn the internal
foundation into a licensed postal, customs, insurance, dangerous-goods, GS1,
or carrier network; those connections remain provider and jurisdiction
release gates.
